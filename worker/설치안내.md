# AI 중계 Worker 설치 (처음 한 번)

시험 등록 화면의 ‘AI로 문항표 채우기’는 이 Worker를 거쳐 Claude나 GPT를 부릅니다.
API 키는 Worker에만 들어가고, 웹 화면(GitHub Pages)에는 들어가지 않습니다.
원장님 Google 계정으로 로그인한 요청만 통과합니다.

## 1. API 키 만들기 (둘 중 하나, 또는 둘 다)

- **Claude**: console.anthropic.com 로그인 → Settings → API Keys → Create Key. 결제(Billing)에 크레딧을 먼저 충전해야 합니다.
- **GPT**: platform.openai.com 로그인 → API keys → Create new secret key. 결제 수단 등록이 필요합니다.

키는 한 번만 보여 주므로 바로 2단계에 붙여 넣습니다. 채팅이나 메모에는 남기지 마세요.

## 2. Worker 만들기

1. dash.cloudflare.com 로그인 → 왼쪽 **Workers & Pages** → **Create** → **Worker** (Hello World)
2. 이름: `sudo-naesin-ai` → **Deploy**
3. **Edit code** → 원래 코드를 모두 지우고 이 폴더의 `worker.js` 내용을 통째로 붙여 넣기 → **Deploy**
4. Worker 화면 → **Settings** → **Variables and Secrets** → **Add**
   - Type: **Secret**, Name: `ANTHROPIC_API_KEY`, Value: Claude 키
   - (GPT도 쓰면) Type: **Secret**, Name: `OPENAI_API_KEY`, Value: GPT 키
   - **Deploy**
5. Worker 주소 복사: `https://sudo-naesin-ai.○○○.workers.dev`

## 3. 앱에 연결

hongs-sudo.github.io/naesin-analysis → **시험 등록** → 오른쪽 **AI 연결**
→ 중계 주소 붙여 넣기 → Claude 또는 GPT 고르기 → **저장** → **연결 확인**

‘연결됐습니다. Claude 키 있음’이 나오면 끝입니다.

## 바꿀 때

- 허용 계정을 늘리려면 `worker.js` 맨 위 `ALLOWED_EMAILS`에 추가하고 다시 Deploy. (Firestore 보안 규칙에도 같은 계정을 넣어야 합니다.)
- 키를 바꾸려면 4번에서 Secret 값만 바꿉니다.
